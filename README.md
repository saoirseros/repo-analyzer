# GitHub Repository Analyzer

An agentic AI app that takes a GitHub repository URL, explores it using GitHub API tools,
and generates an architectural explanation, code quality issues and improvement suggestions.

**Stack:** Python, GitHub API, OpenAI API, LangChain, Streamlit

## Setup

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env   # then fill in your keys
```
